# Changelog

## [0.6.2]

### Documentation

- Document `clear`, `progress`, and contextual Shelly LSP completion.

## [0.6.1]

### Added

- Automatically register the purple Shelly file icon when `nvim-web-devicons` is available.
- Highlight the `clear` and `progress` commands.

## [0.6.0]

### Added

- Highlight final Shelly menu forms: key modes, keyed or unkeyed options, and blank shellout rows.
- Remove obsolete menu layout directives from syntax highlighting.

## [0.5.0]

### Added

- Add syntax highlighting for Shelly structured automation keywords: `retry`, `pipeline`, and `parallel`.

## [0.4.0]

### Added

- Add syntax highlighting and documentation for Shelly `httpPages`, `maxPages`, and `maxTotalBytes`.

## [0.3.0]

### Added

- Add syntax highlighting for `mock` and `secret` commands.

## [0.2.0]

### Added

- Add syntax highlighting for archive v1 commands.

## [0.1.4] - 2026-10-21

### Added

- Configure the LSP workspace root from project markers.
- Add HTTP syntax highlighting.

## [0.1.3] - 2026-10-19

### Added

- Add syntax highlighting and support for Shelly `watch`/`wait` processes.

## [0.1.2] - 2026-10-18

### Added

- Highlight regex literals in Shelly syntax files.
- Highlight the `matches` predicate.
- Document that recursive `**` file-glob diagnostics, completion, and validation are provided by `shelly-lsp`.
